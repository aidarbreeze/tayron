# 20 сквозных тестов лепки кузова

`tests/app20.mjs` — сценарные тесты редактора: настоящий `suspension/sculpt.js`, собранный в модуль,
настоящий three, настоящий `suspension/assets/body.glb` (52657 вершин / 105822 грани, U = 5.8824).
Кнопки нажимаются так же, как мышью в браузере, штрихи идут через `pointerdown/move/up`.

## Запуск

```sh
sh tests/run20.sh          # 20 сквозных тестов приложения, ~26 с
sh tests/run_box.sh        # 13 проверок куба-рамки, ~4 с
sh tests/run_ux.sh         # 16 проверок удобства (клавиши, память настроек), ~12 с
sh tests/run_all.sh        # всё сразу
node tests/burn_cut.mjs    # 18 проверок «прожечь» (после mkharness.sh)
node tests/rope_half.mjs   # 17 проверок «впаять»
```

Печатают строки ok/FAIL и `ИТОГ: N ok, M провалов`; код возврата 1 при провале.

Общий шаг — `tests/mkharness.sh`, он делает всё нужное:

1. `tests/mkbody.py` — достаёт кузов из `suspension/assets/body.glb` в `tests/body.json`
   (файл большой и производный, поэтому он в `.gitignore`);
2. собирает `tests/.harness/sculpt_real.mjs` из `suspension/sculpt.js` (подменяет `from 'three'`
   и `./meshops.js` на абсолютные пути — так же, как это делает браузер);
3. дальше `node tests/app20.mjs` и/или `node tests/frame_box.mjs`.

Код возврата 1, если хоть один тест провалился.

## Почему такие допуски

* «Глубина» у «Выдавить»/«Вдавить» — не жёсткий штамп: поле сглаживается (`soft`), поэтому
  проверяется **максимум** сдвига, а не каждая вершина.
* Сохранение проекта округляет координаты до 1e-4 ед. (1.7e-5 мм), поэтому «байт в байт» для
  JSON-проекта — это < 0.001 мкм; для отмены/сброса сравнение строгое (`=== 0`).

## Тесты не «зеленеют на пустом месте» (проверено мутациями)

* убрали `addEventListener('click')` у кнопки «− ⊽ Упростить» → тест 4 FAIL
  («19 из 20 переключений»), код возврата 1;
* умножили глубину выдавливания на 0.5 → тесты 8 и 9 FAIL («0.300 мм при
  заданных 0.60»), код возврата 1.

После каждой мутации `suspension/sculpt.js` возвращался байт в байт, полный
прогон — снова 20 из 20.

## Куб-рамка (`tests/frame_box.mjs`, 13 проверок)

Инструмент **«7 ▭ Рамка»** ставит на место растянутой рамки 3D-куб: его тащат за
центральную ручку (или `Shift` + протяжка внутри), тянут за шесть граней-ручек,
переворачивают кнопкой «⇄ Сторона» (направление зеркалирования).

| № | Проверка | Результат |
|---|---|---|
| 1 | рамка ставит куб | 57.7 × 33.4 × 29.6 мм, 8 047 вершин |
| 2 | куб = габарит рамки + вся толщина борта | 3 596 из 3 626 узлов рамки внутри, толщина 33.7 мм |
| 3 | направление по умолчанию | «источник правая → копия левая» |
| 4 | «⇄ Сторона» | куб на левой стороне (y 0.3…33.7), 8 437 вершин |
| 5 | перенос за центральную ручку | 40 px → 4.1 мм, размер тот же |
| 6 | грань `+X` меняет размер | 73.9 → 76.4 мм, `x0` на месте |
| 7 | через плоскость симметрии нельзя | упор в 0.25 мм |
| 7b | `Shift` + протяжка внутри куба | сдвиг 2.9 мм |
| 8 | «Зеркально» из куба | граней 105 822 → 104 256, дыр 0, неманиф 0 |
| 9 | куб пережил копию | стоит там же |
| 10 | «✕ Убрать куб» | выделение 3 786 вершин осталось |
| 11 | видимость по инструменту | виден только у «Рамки» |
| 12 | «Сброс» | куба нет, выделения нет |

Ручки «берутся мышью» по-настоящему: тест считает экранные координаты ручки
(`sculpt.boxHandleAt`), жмёт `pointerdown`, ведёт `pointermove` и отпускает —
дальше работает тот же код, что и в браузере (луч по ручкам, плоскость экрана
для переноса, ближайшая точка на оси для грани).

## Удобство (`tests/ux_tools.mjs`, 16 проверок)

Нажатия подаются так же, как их видит браузер: отдельно `e.key` и `e.code`,
поэтому проверяется в том числе **русская раскладка**.

| № | Проверка | Результат |
|---|---|---|
| 1 | `Ctrl+Z` при `key = «я»`, `code = KeyZ` | сглаживание 0.129 мм отменено ровно в исходник |
| 2 | возврат `Ctrl+Shift+Z` и `Ctrl+Y` (`key = «Я»`/«н») | сдвиг 0.129 мм = тот же |
| 3 | `Ctrl+S` при `key = «ы»` | сохранил проект (`dirty` → false), диалог браузера не открылся |
| 4 | `[` `]` при `key = «х»/«ъ»` | кисть 1.2 → 0.7 → 1.7 мм |
| 5 | `Enter` повторяет последнее действие | «Сгладить» 0.193 мм, повтор 0.111 мм |
| 6 | пробел — тоже повтор | ещё 0.085 мм |
| 7 | `Enter`, когда повторять нечего | «повторять нечего — сначала «Сгладить»…» |
| 8 | «Кисть» общая у участка/ластика/пера | 1.2 → 3 → 3 → 3 |
| 9 | «Ширина» борозды не трогает кисть участка | участок 1.5 мм, борозда 4 мм |

| 12 | метка «●» на «💾 Сохранить» | «💾 Сохранить» → «💾 Сохранить ●» → снова без точки |
