# Пересмотр интерфейса: редактор кузова на первом плане

Просьба: «пересмотри интерфейс чтоб было удобно пользоваться, сверни меню работы с
подвеской, это уже не актуально». Ниже — что перестроено и чем это проверено.

## Что было и что стало

| было | стало |
|---|---|
| `#ctrl` слева снизу, 330 px: **сценарии нагрузки → ползунки → настройки → сборка** и только потом «Редактор кузова» внизу длинной панели | `#ctrl` слева снизу, 340 px — **только редактор**: «Инструменты» → «Вид и проверка» → «Правка и печать» |
| подвеска занимала всю левую панель, до кистей нужно было прокручивать | подвеска целиком в **одном свёрнутом блоке «Подвеска · демо»** справа сверху (`<details>`, как «Как это устроено») |
| телеметрия — отдельная правая панель `#tele` всегда раскрыта | телеметрия внутри свёрнутого блока, рядом со сценариями и ползунками: всё про подвеску в одном месте |
| «Как это устроено» — третья правая панель | вложенный `<details>` внизу демо-блока |
| подсказка «Клик по кузову — надавить» внизу по центру | подсказка по кистям и клавишам, между панелями |
| шапка `#head` — описание подвески на 330 px | шапка — что делает редактор + горячие клавиши |

## Что появилось в редакторе

* **Чип активного инструмента** в шапке панели: «просмотр», «участок», «ластик»,
  «перо», «фигура», «точка», «измерение» — видно, в каком режиме находишься,
  даже когда кнопка ушла из поля зрения.
* **Горячие клавиши 1…6** — кисти, **Esc** — выйти, **[** / **]** — кисть
  ±0.5 мм (в пределах 0.1…20 мм), Ctrl+Z / Ctrl+Shift+Z — как раньше.
  В ползунках клавиши не перехватываются.
* Цифра клавиши напечатана на кнопке («1 ✎ Участок»), активная кнопка
  подписана «■ Готово (участок)».
* Одинаковые короткие подписи в разметке и в JS: «◐ Видимые грани» / «◐ Все
  грани», «▦ Сетка» / «▦ Сетка вкл», «◧ Сечение» / «◧ Сечение вкл».

## Проверено (не на глаз)

В песочнице нет ни Chromium, ни Playwright (`npm ls -g` — только corepack и npm),
поэтому вёрстка проверена статически, а поведение — прогонами Node со стабом
`three` и DOM.

| стенд | что проверяет | результат |
|---|---|---|
| `ui_ids.mjs` | каждый `id`, который ищет JS, есть в разметке | 72 id в HTML, 50 ищет JS, **0 потеряно** |
| `ui_css.mjs` | у каждого класса в HTML есть правило, у каждого `#id`-селектора — элемент | 28 классов, 86 правил, **0 висячих** |
| `ui_wiring.mjs` | 23 сборки: уникальность id, вложенность тегов, кнопки сценариев ↔ `PRESETS`, 9 стартовых подписей кнопок, скобки CSS (86/86), прокрутка `#ctrl`, свёрнутость демо, 25 id в `main.js` | **23 ok / 0** |
| `ui/keys.mjs` | клавиатура и чип: 1…6, повторное нажатие, Esc, игнор в ползунке, `[`/`]` (3 → 4 → 2 мм), границы 0.1 и 20 мм, подпись = ползунок | **17 ok / 0** |
| `tools_audit.mjs` | 44 сценария редактора (кисти, фигуры, ластик, отмена, проверка) | **44 ok / 0** |

Сервер предпросмотра (`http://localhost:8123`, корень — `suspension/`) отдаёт
все модули: `index.html` 21.9 КБ, `main.js` 30.3 КБ, `sculpt.js` 75.9 КБ,
`meshops.js` 40.0 КБ, `export3mf.js` 8.2 КБ, `vendor/three.module.js` 670.7 КБ,
`assets/body.glb` 2.16 МБ — все 200.

Что осталось непроверенным: сама картинка в браузере (теней, шрифтов и
переполнения панели на нестандартном экране) — в песочнице нечем открыть;
панель редактора прокручивается (`max-height: calc(100vh − 190px)`), демо-блок
тоже (`calc(100vh − 90px)`), подсказка внизу скрывается уже на 1180 px.

## Второй заход: чего не хватало в самих инструментах

После перестройки панелей остались дырки в логике, которые в работе чувствуются
сильнее оформления. Что добавлено и чем проверено (`ui/extras.mjs`, **33 проверки**):

| чего не хватало | что сделано | проверка |
|---|---|---|
| закрашенный участок нельзя было снять — только «Сбросить» всё | кнопка **✕ Снять выделение** (с числом вершин) + клавиша **0**; отменяется Ctrl+Z, потому что выделение входит в снимок истории | снятие обнуляет выделение, отмена возвращает 1589 вершин, повторная 0 говорит «выделения нет» |
| при переключении на другой инструмент бирюзовая подсветка висела поверх модели и путала | подсветка показывается только в «Участке» и в просмотре; данные не теряются, в строке состояния пишется «выделение сохранено: N вершин — клавиша 1 вернёт к нему» | подсветка скрыта/появляется, `regionCount` сохраняется |
| **Shift+ластик** ничего не делал (Shift читался, но ластик его игнорировал) | Shift — точечное удаление: уходит один ближайший узел | кисть 6 мм: 1200 узлов за клик, с Shift — ровно 1; сетка после этого замкнута (0 открытых рёбер) |
| **«Фигура»** работала только одиночным кликом: тянешь — ничего не происходит | штрих фигурой: штампы вдоль следа с шагом 0.9 радиуса кисти, до 6 за штрих, маска видимых граней пересчитывается на каждом шаге, весь штрих — одна запись истории | 6 штампов за протяжку, вмятина 2.09 мм, 0 дырок / 0 флипов, отмена возвращает всё (0.0000 мм) |
| правку нельзя было продолжить после перезагрузки — только выгрузить готовую печать | **💾 Сохранить / 📂 Открыть** и **Ctrl+S**: в `.json` пишутся сдвинутые вершины, маски (выделение, удалённые, добавленные) и изменённые индексы (упакованы как «общее начало + середина + общий конец»); при закрытии вкладки с несохранённой правкой браузер спрашивает подтверждение | правка 1135 сдвинутых вершин и 2 добавленных узла: загрузка даёт те же 59654 верт. / 117130 граней, расхождение координат 0.00001 мм, маски и топология на месте, загрузка отменяется Ctrl+Z; чужой файл отвергается с объяснением |

Размер файла правки: **0.2 КБ** (только выделение), **46 КБ** (1191 сдвинутая
вершина), **886 КБ** (ластик переписал индексы — тогда в файл идёт упакованная
середина индексного массива).
